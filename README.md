## spill-the-tea-web 프로젝트 소개
DEPth 3th Main Project [Spill the Tea] 프론트 레포지토리입니다.
spill the tea는 영어 속어로, 누군가가 비밀이나 흥미로운 소식을 이야기할 때 사용되는 표현입니다. 짤 위주의 게시판과 tts를 사용하여 이야기가 재미있고 흥미롭게 느껴지게 합니다.
